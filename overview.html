Three.js learning prototypes

Interactive mechanics, ready to embed

Each prototype is a self-contained folder: one HTML file, one script, one content file. No build step and nothing to install — drop the folder on a server and put it in an <iframe>. All the learner-facing wording lives in content.js, so a topic swap never touches the 3D code.

Embedding these in WordPress

  • Upload the whole project folder to your host, for example /wp-content/uploads/prototypes/.
  • Embed the carousel with <iframe src="/wp-content/uploads/prototypes/" width="100%" height="860"></iframe>, or a single prototype with its own folder path at 640px tall.
  • Each prototype posts ready, progress and complete messages to the parent page — see README.md for the listener snippet.
  • They need WebGL and a modern browser. Nothing is written to the server and no data leaves the page.
